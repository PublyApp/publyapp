# Docs

This folder is organized by intent. Keep new docs inside an existing category.

## Index
- `docs/analysis/` - Deep dives, tradeoffs, and design analysis.
- `docs/audits/` - Audits and gap analyses.
- `docs/changes/` - Change summaries and post-implementation notes.
- `docs/front/` - Frontend-specific planning notes.
- `docs/guides/` - How-to guides and canonical practices.
- `docs/implementation-plans/` - Detailed step-by-step implementation plans.
- `docs/implementation-summaries/` - Summaries of completed work.
- `docs/misc/` - Reference notes and scratch research.
- `docs/plans/` - High-level plans and issue planning.
- `docs/refactoring-guides/` - Refactor playbooks and checklists.
- `docs/reviews/` - Reviews, review prompts, and follow-ups.
- `docs/roadmaps/` - Multi-phase roadmaps.

## Notes
- Architecture and vertical-slice rules live in `AGENTS.md`.
- Avoid adding new files at the `docs/` root.
- Update cross-links when moving or deprecating docs.
