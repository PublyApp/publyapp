## Style Reference Guide

Use this block as a **prefix/context** when generating illustrations. All 50 prompts use this same style:

```
STYLE: Icons8 "Taxi" illustration style.
- Strict 3-color flat palette: warm golden yellow (#F5C518), black, and white. No other colors, no gradients.
- Bold, clean, uniform-thickness black outlines on all shapes.
- Large organic amoeba/blob-shaped yellow background behind the main subject, on a white canvas.
- Characters (when present): stylized, slightly exaggerated proportions with large torsos and relatively small heads. Skin is rendered in the same golden yellow. Hair and shoes are black. Clothing mixes white shirts/tops with yellow pants/skirts featuring black decorative patterns (stripes, swirls, abstract shapes).
- White highlights and reflections on yellow surfaces for subtle dimensionality.
- Objects: clean, bold, graphic — screens are black with white/yellow UI elements.
- Overall mood: modern, professional, slightly playful, retro-influenced.
- No text in the illustration (text will be added separately in the app).
- Transparent or white background outside the yellow blob.
- Square aspect ratio (1:1).
```

## Tips for Best Results in ChatGPT

1. **Paste the full style block + scene description together** as a single prompt.
2. **If ChatGPT adds unwanted colors**, re-prompt with: "Remember: ONLY golden yellow (#F5C518), black, and white. Remove all other colors."
3. **If characters look too realistic**, add: "Make the character more stylized and cartoonish with exaggerated proportions."
4. **If the background blob is missing**, add: "Add a large organic amoeba-shaped golden yellow blob behind the subject."
5. **Request PNG with transparent background** if you want to embed in the app: "Export with transparent background outside the yellow blob area."
6. **Iterate:** If the first result is close but not perfect, describe what to change rather than regenerating from scratch.
7. **Upload a reference image** from `.dump/Icons8-Taxi-Style-Illustrations/` alongside the prompt for better style matching.
