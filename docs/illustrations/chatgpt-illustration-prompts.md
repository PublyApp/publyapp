## Style Reference Guide

Use this block as a **prefix/context** when generating illustrations. All 155 prompts use this same style:

```
STYLE: Icons8 "Taxi" illustration style.
- Strict 3-color flat palette: warm golden yellow (#F5C518), black, and white. No other colors, no gradients.
- Bold, clean, uniform-thickness black outlines on all shapes.
- Large organic amoeba/blob-shaped yellow background behind the main subject, on a white canvas.
- No human figures or characters — objects and symbols only.
- White highlights and reflections on yellow surfaces for subtle dimensionality.
- Objects: clean, bold, graphic — minimal elements, avoid clutter.
- Screens are black with white/yellow UI elements.
- Overall mood: modern, professional, slightly playful, retro-influenced.
- No text in the illustration (text will be added separately in the app).
- Transparent or white background outside the yellow blob.
- Square aspect ratio (1:1).
```

## Tips for Best Results in ChatGPT

1. **Copy the full prompt** (STYLE + SCENE) into ChatGPT in one message.
2. **Keep it simple** — these prompts use minimal elements intentionally. Resist adding detail.
3. **Regenerate 2–3 times** per prompt — quality varies between generations.
4. **Check the 3-color rule** — if the output has extra colors, add "Strictly only golden yellow, black, and white" as a follow-up.
5. **No people = cleaner output** — object-only scenes produce fewer artifacts and distortions.
6. **Request transparency** — if needed, ask ChatGPT to "make the background outside the yellow blob transparent."
7. **Consistent naming** — save files using the prompt ID (e.g., `404-Taxi-1.png`, `EMPTY-Taxi-3.png`).
8. **Batch efficiently** — generate all 5 variants for one type, then pick the best before moving to the next type.
