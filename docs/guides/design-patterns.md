# Design patterns in PublyApp

The rules themselves: [`docs/conventions/design-patterns.md`](../conventions/design-patterns.md) and
[`docs/conventions/solid.md`](../conventions/solid.md) (verbatim local copies of the shared rules from
radandevist/conventions).
This page only maps them onto PublyApp: what already follows, and the few places where a sign is present.
No problem, no pattern: a row below is a place to look, not a refactor to schedule.

## Already in PublyApp

| Pattern                 | Where (real file / type)                                                                                                                                                                                                                       | Note                                                                                 |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| Adapter                 | `apps/api/Infrastructure/Messaging/Email/ResendEmailAdapter.cs` (`ResendEmailAdapter : IEmailSender`); `apps/api/Modules/Aggregators/Adapters/Zernio/ZernioAggregatorAdapter.cs`                                                                 | Resend and Zernio types stay inside the adapter.                                      |
| Adapter                 | `packages/shared-ts/src/lib/logger/adapters/winston-logger-adapter.ts`, `stdout-json-logger-adapter.ts`                                                                                                                                        | One adapter per medium; the service filters and redacts first.                        |
| Strategy                | `apps/api/Modules/SocialAccounts/Adapters/SocialAdapterRegistry.cs`; `apps/api/Modules/Publishing/Providers/RoutingPublishAdapter.cs`                                                                                                           | The network is a dictionary key, not a `switch` in the publish job.                   |
| Facade                  | `apps/api/Infrastructure/Messaging/Email/EmailService.cs`; `packages/shared-ts/src/lib/analytics/analytics.ts`                                                                                                                                  | One call owns render + send / consent + mask + send.                                  |
| Decorator               | `apps/api/Lib/Logging/SanitizingLogEventSink.cs`; wiring in `apps/api/Lib/Logging/SanitizingSinkConfigurationExtensions.cs`                                                                                                                    | Wraps every durable sink; redaction is added, not edited into each sink.              |
| Proxy                   | `apps/api/Infrastructure/Storage/ReparsePointExclusionFileProvider.cs`                                                                                                                                                                         | Same `IFileProvider`; hides symlinked entries from the static-file middleware.        |
| Template Method         | `apps/api/Modules/Messaging/Jobs/EmailJobHandlerBase.cs`; handlers such as `apps/api/Modules/Invitations/Jobs/TenantInvitationEmailJobHandler.cs`                                                                                              | The base owns the transaction and provider contract; subclasses prepare and render.   |
| Factory Method          | `packages/shared-ts/src/lib/logger/index.ts` (`resolveAdapter`); `apps/api/Lib/CursorSortFieldHandlerFactory.cs`                                                                                                                                | Environment or key type selects the implementation at one boundary.                   |
| Chain of Responsibility | `apps/api/Lib/Filters/SessionAuthFilter.cs`; `apps/api/Lib/Filters/TenantPermissionFilter.cs`                                                                                                                                                  | Each filter checks, then calls `next(context)`; a failure returns early.              |
| Command                 | `apps/api/Infrastructure/Jobs/JobDefinition.cs`; `apps/api/Infrastructure/Jobs/IJobHandler.cs`                                                                                                                                                 | A stored job definition plus an executor keyed by `JobType`; the queue owns retries.  |
| Observer                | `apps/front/src/lib/tab-sync/broadcast-sync.ts`                                                                                                                                                                                                | `postBroadcast` publishes, `useBroadcastSync` subscribes; auth/theme/locale sync.     |
| Null Object             | `apps/api/Modules/SocialAccounts/Providers/Bluesky/BlueskySocialAdapter.cs` (`NullLogger<BlueskySocialAdapter>.Instance`)                                                                                                                       | A missing optional logger is a no-op, not a null check in every call.                 |

## Candidates

Real signs present today. The last column says when the pattern would be worth its cost; until then, leave it.

| Sign today                                                                                                 | Where                                                                                                                                                                                          | Pattern that would fit                            | Trigger                                                                                       |
| ---------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------- | --------------------------------------------------------------------------------------------- |
