## How to sign

Signing is a one-time action. It covers all of Your past and future
contributions to this repository.

1. Add a line for yourself to [`CLA-SIGNATURES.md`](CLA-SIGNATURES.md), in the
   format shown at the top of that file.
2. Include that change in your first pull request, or open a pull request
   containing only that change.
3. In the pull request body, write exactly:

   > I have read the PublyApp Contributor License Agreement and I accept it for
   > my present and future contributions to this repository.

A maintainer will not merge a code contribution from an unsigned contributor.

### Contributing on behalf of a company

If you contribute as part of your employment, your employer may own the
copyright. In that case, someone authorised to bind the company must sign on
its behalf: add the company row to `CLA-SIGNATURES.md` and state the signer's
role in the pull request body.

### Questions

If any clause is unclear, or if section 4 is a problem for you, open an issue
before contributing. It is better to raise it early than to have a pull request
blocked at merge time.
